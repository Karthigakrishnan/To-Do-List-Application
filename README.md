To-Do List Application in Python 📝
This is a simple and interactive To-Do List application built using Python. It allows users to manage their tasks by adding, viewing, completing, and deleting tasks. The application stores tasks persistently using the pickle module, ensuring that your tasks are saved even when the program is closed and reopened.

Features 🚀
      View Tasks 👀: Displays all tasks with their current completion status.
      Add Task ➕: Allows you to add new tasks to your list.
      Mark Task as Completed ✅: Marks a specific task as completed.
      Delete Task 🗑️: Deletes a task from the list.
      Persistent Storage 💾: Tasks are saved between sessions using pickle.
  
  Requirements ⚙️
  Python 3.x
  pickle (Python’s built-in library)
